# identity-site

תרגיל בית 1 – **תעודת זהות: סדר ושבירה**
קורס *עיצוב בעזרת בינה מלאכותית* (38204-1), תואר שני בעיצוב לסביבה טכנולוגית, HIT.

## סטטוס: דראפט ראשוני

הגרסה הזו היא מימוש ישיר של שלושה פריימים מ-Figma ושל הפלואו שמחבר ביניהם, נקודת המוצא שממנה ממשיכים לעבוד.

`index.html` מציג את שלושת הפריימים לסירוגין, כמו בפרוטוטייפ ב-Figma:
מתחלף כל 1600ms, במעבר מיידי (Instant), בלולאה.

| סדר | פריים ב-Figma | מה יש בו |
| --- | --- | --- |
| 1 | Desktop 5 (`1:34`) | שלוש תמונות בתחתית העמוד |
| 2 | Desktop 4 (`1:57`) | קולאז': תמונה גבוהה במרכז ושני ריבועים בצדדים |
| 3 | Desktop 2 (`1:13`) | תמונה אחת גבוהה במרכז |

`styles.css` מכיל את העיצוב. הפריים מצויר בגודל העיצוב (1440×784) ומוקטן כדי להתאים לחלון, כמו בתצוגת הפרוטוטייפ ב-Figma.

## תמונות

התמונות עוד לא נמצאות ב-repo. העמודים מחפשים אותן בתיקייה `assets/`:

- `assets/hero-trio.png`
- `assets/hero-collage.png`
- `assets/hero-single.png`

כל עוד הן חסרות, מוצג במקומן משטח משובץ, כמו בשכבות הריקות ב-Figma.

## תיעוד תהליך

### איטרציה 1: מ-Figma לקוד

- את שלושת הפריימים מימש Claude ישירות מ-Figma, בלי שינויים בעיצוב.
- בגרסה הראשונה יצאו שלושה עמודים סטטיים, כי האינטראקציות של הפרוטוטייפ לא עוברות לקוד עם העיצוב.
  אחר כך Claude קרא את הפלואו מ-Figma (After delay 1600ms → Navigate) ומימש אותו כעמוד אחד שמתחלף.
- התוצאה היא Hero ממורכז, גופן Inter, תפריט ממורכז ושם גדול באמצע. בלשון התרגיל זו הטופסולוגיה:
  סדר בלי החלטה, מה שהכלים מייצרים כברירת מחדל.
- את זה צריך להמשיך מכאן: שכבת סדר מודרניסטי מודעת (גריד, סקאלה טיפוגרפית), שבירה אישית,
  וטקסט עמדה של 300–500 מילים.
